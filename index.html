About me

I'm a frontend developer who cares about the details most people scroll right past — the smooth load, the layout that holds up at 320px, the interaction that just feels right.

I got into web development chasing one idea: that a site shouldn't just look good in a screenshot, it should feel good to use. Since then I've been shipping responsive interfaces — landing pages, utility apps, API-driven tools — and sharpening my craft with every build.

Right now I'm a Web Development Intern at Prodigy InfoTech, building responsive web applications and modern user experiences. I obsess over clean markup, performance across devices, and writing code I'd actually want to maintain. Always learning, always shipping.
